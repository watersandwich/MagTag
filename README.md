# MagTag

OUTPOST // 01: a weather station for the Adafruit MagTag 2.9" grayscale e-ink
board, running CircuitPython. Weather comes from [Open-Meteo](https://open-meteo.com/)
(no API key needed).

## Buttons

| Button | Screen |
| --- | --- |
| A | Home: current temperature and conditions; the city outside M-01's window changes with the weather and time of day (hold ~2 s to refresh the weather) |
| B | 5-day forecast with icons |
| C | Today: a written forecast for the next 18 hours plus details (feels-like, wind, gusts, humidity, UV, sunrise/sunset) |
| D | Signal Decoder: a Simon-style memory game on the lights and speaker (hold D ~2 s to leave) |

## Signal Decoder

M-01 plays a pattern on the four NeoPixels, with a tone for each light: A red, B yellow,
C green, D blue. Repeat it with the buttons. Each round adds one step and plays a little
faster. A wrong button, or 6 seconds without a press, ends the game. Your best score is
saved on the board and survives power-off.

Settings at the top of `code.py`:

- `SOUND = False` plays silently; `VOLUME` (0-32768) sets loudness.
- `LED_FOR_BUTTON` sets which light sits above which button. If the lights come on in
  reverse order on your board, change it to `(3, 2, 1, 0)`.

## Battery and sleep

The MagTag spends almost all its time in deep sleep. The e-ink screen keeps its picture
with no power, so you won't see a difference.

- **Every 30 minutes** (hourly from 11pm to 6am) it wakes, fetches the weather, redraws
  the home screen and goes straight back to sleep. Status lights stay off during these
  wakes so it never blinks at night.
- **Any button** wakes it and shows that button's screen right away, using the saved
  forecast without reconnecting to Wi-Fi. It stays awake for 60 seconds after your last
  press, then returns to the home screen and sleeps. The game stays awake while you play
  and gives up after 3 idle minutes.
- **The home screen shows "awake 3:42p"** in the top bar: the last time the board woke
  up. If that time is much more than an hour old, the board has stopped waking (usually
  a flat battery).
- **"OFFLINE"** in the top-right panel means the last update failed. It retries after
  5 minutes, then 10, 20 and 30. **"LOW BAT"** appears below 3.5 V.
- Wi-Fi is switched off between updates, and the lights and speaker are only powered
  while in use.

The timings are at the top of `code.py` (`UPDATE_SECONDS`, `NIGHT_UPDATE_SECONDS`,
`AWAKE_SECONDS`, and so on).

While the MagTag is plugged into a computer over USB, CircuitPython only pretends to
deep sleep, so the serial console keeps working. The battery savings only apply on
battery.

## Installing on the MagTag

Copy these to the root of the `CIRCUITPY` drive:

- `code.py`
- every `.bmp` file in this repo
- `settings.toml` with your own Wi-Fi details. See `settings.toml.example`: the first network
  is `CIRCUITPY_WIFI_SSID` / `CIRCUITPY_WIFI_PASSWORD`, and you can add more as
  `WIFI_SSID_2` / `WIFI_PASSWORD_2` up to `_9`. The MagTag tries the network that worked
  last time first, then the others it can see, strongest signal first.

The `lib/` folder needs `adafruit_requests`, `adafruit_connection_manager` and
`neopixel` from the Adafruit CircuitPython library bundle.

The game's sound uses the built-in `pwmio` module, so it needs no extra library.

To change the location, edit `LATITUDE`, `LONGITUDE` and `LOCATION_LABEL` at the top of `code.py`.

## Editing the artwork

The icons, the Today screen background and the 6x13 text font are generated by a script:

```bash
python3 tools/make_assets.py --preview icons-preview.png
```

The home screen's window views (`scenes.bmp`) come from `home.bmp`. This script keeps the
robot and room, and repaints the city outside for each kind of weather: clear, partly
cloudy, cloudy, fog, rain, snow, storm, plus clear, partly cloudy and cloudy at night.

```bash
python3 tools/make_scenes.py --preview scenes-preview.png
```

To check the screens on a computer without the MagTag, run `tools/preview.py`.
It runs the real `code.py` drawing code with CircuitPython stand-ins and writes
PNGs to `preview/`. Both tools need Pillow (`pip install pillow`).
