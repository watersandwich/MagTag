# MagTag

OUTPOST // 01: a weather station for the Adafruit MagTag 2.9" grayscale e-ink
board, running CircuitPython. Weather comes from [Open-Meteo](https://open-meteo.com/)
(no API key needed).

## Buttons

| Button | Screen |
| --- | --- |
| A | Home: current temperature and conditions (hold ~2 s to refresh the weather) |
| B | 5-day forecast with icons |
| C | Today: a written forecast for the next 18 hours plus details (feels-like, wind, gusts, humidity, UV, sunrise/sunset) |
| D | Reactor mini-game (hold D ~2 s to leave) |

## Installing on the MagTag

Copy these to the root of the `CIRCUITPY` drive:

- `code.py`
- every `.bmp` file in this repo
- `settings.toml` with your own Wi-Fi details (`CIRCUITPY_WIFI_SSID`, `CIRCUITPY_WIFI_PASSWORD`)

The `lib/` folder needs `adafruit_requests`, `adafruit_connection_manager` and
`neopixel` from the Adafruit CircuitPython library bundle.

To change the location, edit `LATITUDE`, `LONGITUDE` and `LOCATION_LABEL` at the top of `code.py`.

## Editing the artwork

The icons, the Today screen background and the 6x13 text font are generated by a script:

```bash
python3 tools/make_assets.py --preview icons-preview.png
```

To check the screens on a computer without the MagTag, run `tools/preview.py`.
It runs the real `code.py` drawing code with CircuitPython stand-ins and writes
PNGs to `preview/`. Both tools need Pillow (`pip install pillow`).
